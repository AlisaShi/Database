# 山上優雅 (Elegant on the Mountain)

一個專為台灣森林遊憩區和步道設計的互動式地圖平台，讓使用者能夠輕鬆探索台灣的自然景點和登山步道。

## 專案概述

山上優雅是一個基於 PHP 和 MySQL 的網頁應用程式，提供台灣森林遊憩區、步道和相關設施的完整資訊。平台整合了互動式地圖、搜尋功能、使用者帳戶管理和行政管理系統。

## 主要功能

### 🗺️ 互動式地圖
- **景點地圖**: 顯示台灣各地的森林遊憩區、生態教育館、林業文化園區等設施
- **步道地圖**: 展示超過 100 條登山步道，包含 KML 軌跡檔案
- **林道地圖**: 森林道路地圖視覺化

### 🔍 搜尋與探索
- 依名稱或描述搜尋景點
- 依地區篩選天氣預報
- 依步道名稱篩選最新消息

### 👤 使用者功能
- 使用者註冊與登入
- 收藏喜愛的景點
- 個人化儀表板

### 🌤️ 天氣與資訊
- 各地區天氣預報
- 步道相關最新消息和公告
- 步道開放/關閉狀態資訊

### 🛠️ 管理系統
- 景點管理 (新增/編輯/刪除)
- 步道管理
- 使用者權限管理
- 部門管理

## 技術架構

### 前端
- **HTML/CSS/JavaScript**: 基礎網頁結構和樣式
- **Leaflet.js**: 互動式地圖渲染
- **Leaflet-Omnivore**: KML 檔案載入和顯示

### 後端
- **PHP**: 伺服器端邏輯處理
- **MySQL**: 資料庫儲存和管理

### 資料結構
- **location_info**: 景點基本資訊 (名稱、座標、類型、描述等)
- **trail**: 步道資訊 (長度、海拔、難度等)
- **user**: 使用者帳戶管理
- **weather_forecast**: 天氣預報資料
- **news**: 最新消息和公告

## 景點類型

平台包含以下類型的設施：

1. **國家森林遊樂區** - 如太平山、滿月圓、東眼山等
2. **生態教育館** - 提供環境教育和生態展示
3. **林業文化園區** - 展示台灣林業歷史
4. **林業鐵路** - 阿里山森林鐵路等特色鐵路
5. **自然教育中心** - 戶外學習場域
6. **平地森林園區** - 都市中的森林空間

## 步道特色

- **難度分級**: 1-5 級難度分類
- **詳細資訊**: 長度、海拔高度、建議季節等
- **KML 軌跡**: 精確的 GPS 軌跡檔案
- **即時狀態**: 開放/關閉狀態追蹤

## 安裝與設定

### 系統需求
- PHP 8.0+
- MySQL 5.7+
- 網頁伺服器 (Apache/Nginx)

### 資料庫設定
1. 建立 MySQL 資料庫 `20240608`
2. 匯入 `20240608-2.sql` 檔案
3. 設定 `db_config.php` 中的資料庫連線資訊

### 檔案結構
```
/home/jc/Projects/Database/
├── index.php              # 首頁 - 景點地圖
├── trails.php             # 步道地圖頁面
├── leaflet.php            # 林道地圖頁面
├── weather.php            # 天氣預報頁面
├── news.php               # 最新消息頁面
├── search.php             # 搜尋功能
├── login.php              # 使用者登入
├── register.php           # 使用者註冊
├── manage_*.php           # 管理頁面
├── details.php            # 景點詳細資訊

├── TR_KML/                # KML 軌跡檔案
└── *.sql                  # 資料庫匯出檔案
```

## 使用說明

### 一般使用者
1. 造訪首頁查看景點地圖
2. 點擊地圖標記查看詳細資訊
3. 註冊帳戶以收藏喜愛景點
4. 查看天氣預報和最新消息

### 管理員
1. 登入管理帳戶
2. 管理景點、步道和使用者資訊
3. 更新天氣資料和公告
